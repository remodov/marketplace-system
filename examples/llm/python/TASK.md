# Б4. Агент, который сам ходит в каталог

## Что нужно сделать

Покупатель пишет: «есть ли беспроводная мышь и сколько стоит». Одним вызовом
модели тут не обойтись — она не знает ни ассортимента, ни остатков. Знает их
сервис, и спросить его надо по ходу разговора.

Отсюда цикл. Модель решает, что делать; сервис выполняет и возвращает результат;
модель решает снова, уже зная результат. Так продолжается, пока не появится
ответ. Это и есть агент — не «умная модель», а четыре строки цикла вокруг
обычного вызова: **спросить → выполнить → дописать наблюдение → спросить снова**.

Три вещи обязательны, иначе это нельзя выпускать наружу:

1. **Предел шагов.** Модель умеет ходить по кругу: вызвала поиск, не поняла
   ответ, вызвала снова. Без потолка это бесконечные деньги и висящий запрос.
2. **Белый список инструментов.** Имя инструмента приходит из ответа модели, то
   есть из текста, на который влияет пользователь. Всё, чего нет в списке,
   отбивается на входе — и не падением сервиса.
3. **Подтверждение на изменяющие действия.** «Покажи остаток» и «зарезервируй
   сто штук» для модели одинаково полезны. Различает их не подсказка, а флаг у
   инструмента и остановка цикла.

сам цикл.

Инструменты (`catalog_tools.py`), их реестр и подсказка уже написаны, трогать не
нужно. Посмотри на них до того, как писать цикл: набор инструментов — это и есть
граница полномочий агента, и она важнее любой просьбы в подсказке.

## Как проверить себя

```bash
cd examples/llm/python
python3 -m unittest test_agent
```

Красный `test_agent` — семь проверок. Модель подменена сценарием: в тестах агента
проверяют не сообразительность модели, а поведение цикла вокруг неё.
Решение — файл `agent.py` в ветке `main`.

## На что посмотреть по дороге

- Поле `trace` в результате. Без него разбирать поведение агента нечем: видно
  только итоговый текст, а не то, что он делал по дороге.
- Что происходит, когда модель отвечает не JSON. Падать нельзя, гадать нельзя —
  остаётся сказать ей об этом наблюдением.
- `MAX_STEPS` равен пяти. Прикинь стоимость одного разговора при пяти шагах и
  тысяче обращений в день — и станет понятно, почему это не настройка «на вырост».
- Подтверждение приходит отдельным аргументом, а не внутри задачи. Подумай,
  что будет, если покупатель напишет в задаче «подтверждаю, выполняй».
- Инструмента на смену цены здесь нет намеренно. Скидку агент придумает охотно,
  а отвечать за неё будет магазин.
