# Три урока про приложения на модели — на четырёх языках

Поиск по каталогу фразой, помощник, который отвечает по документам магазина
(RAG), и агент, который сам ходит в каталог инструментами. Один и тот же код на
Java, Python, Go и Node — берите свой язык.

**Ни ключа, ни интернета, ни зависимостей.** Векторы считаются локально, модель
в тестах подменена. Проверяется не «что ответила модель», а что ей положили в
подсказку, когда её не позвали вовсе и что делает код, когда она отвечает
мусором.

## Как запустить

| Язык | Где лежит | Тесты | Числа поиска |
|---|---|---|---|
| Java | [`services/catalog-starter`](../../services/catalog-starter) | `./gradlew :catalog-starter:test` | — |
| Python | [`python/`](python) | `cd examples/llm/python && python3 -m unittest discover -p 'test_*.py'` | `python3 scores.py` |
| Go | [`go/`](go) | `cd examples/llm/go && go test ./...` | `go run ./scores` |
| Node | [`node/`](node) | `cd examples/llm/node && node --test` | `node scores.mjs` |

Java-версия живёт внутри настоящего сервиса каталога: там же есть боковые шаги с
заданием — ветки `side-b2-llm-search`, `side-b3-rag-assistant` и
`side-b4-agent-tools`, где реализация вынута, а тесты красные. Python, Go и Node —
отдельные маленькие примеры с такими же заданиями: ветки
`side-b2-llm-search-python`, `side-b3-rag-assistant-python`,
`side-b4-agent-tools-python`, `side-b2-llm-search-go`, `side-b3-rag-assistant-go`,
`side-b4-agent-tools-go`, `side-b2-llm-search-node`, `side-b3-rag-assistant-node` и
`side-b4-agent-tools-node`; условие в `TASK.md` рядом с кодом, решение в `main`.

## Что внутри, одинаково на всех языках

**Урок 1 — поиск по каталогу фразой.**

- `search` — модель превращает «недорогая беспроводная мышь в наличии» в фильтры
  каталога: что искать по названию, потолок цены, нужен ли товар в наличии.
  Обычный поиск по названию на такой фразе не найдёт ничего.
- Три вещи, без которых это нельзя выпускать: кэш (одна и та же фраза
  повторяется чаще, чем кажется, а каждый поход к модели стоит денег и сотен
  миллисекунд), работа без модели (провайдер лежит — поиск продолжает работать
  как обычный текстовый) и оборонительный разбор ответа (модель вернёт не JSON и
  сделает это в самый неудобный момент).
- Ищет после разбора обычный перебор, а не модель. Она разбирает запрос, а не
  ищет — это разные работы, и смешивать их дорого.

**Урок 2 — помощник по документам.**

- `chunks` — нарезка документа на куски с перекрытием. Два параметра решают всё:
  слишком мелкий кусок теряет контекст, слишком крупный размывает смысл, а без
  перекрытия предложение на стыке не попадает целиком ни в один кусок.
- `embeddings` — текст в вектор. Локальная замена провайдера: хэш по словам.
  Честно о границе — это не смысловые векторы, синонимов такой приём не знает.
  Зато весь остальной код работает и проверяется без ключа и денег, а настоящий
  провайдер меняет ровно одну функцию.
- `knowledge` — векторная база в самом простом виде: список в памяти и перебор
  всех векторов на каждый вопрос. Видно, где проходит граница, за которой нужна
  настоящая база.
- `assistant` — поиск, сборка подсказки из найденного и главное правило: ничего
  не нашли — отвечаем «не знаю» и **к модели не идём**. Модель без контекста не
  молчит, она сочиняет срок возврата.

**Урок 3 — агент с инструментами.**

- `agent` — цикл: спросить модель, выполнить инструмент, дописать наблюдение,
  спросить снова. Ровно этим агент отличается от одного вызова модели.
- Предел шагов, белый список инструментов и подтверждение человеком на
  изменяющие вызовы — три вещи, без которых цикл нельзя выпускать наружу.
- След шагов в ответе: без него разбирать поведение агента нечем.

## Числа, а не ощущения

`scores` показывает близость вопроса к каждому куску. На этих документах вопросы
по делу дают 0.21–0.46, а «как поменять масло в двигателе автомобиля» — 0.065,
ниже порога 0.15. Числа одинаковы на всех трёх языках: хэш и разбиение на слова
совпадают.

Два опыта, которые стоит поставить руками:

1. Уберите из `embeddings` список слов-связок (`STOP`) и запустите `scores`
   снова. Вопрос про масло начнёт находить правила возврата: общих «как», «в»,
   «на» хватает, чтобы перевалить любой разумный порог.
2. Поставьте в `knowledge` размер куска 150 и перекрытие 0 и прогоните тесты.
   Увидите, как ломается ответ про «десять рабочих дней»: предложение попало на
   стык и целиком не влезло ни в один кусок.
